# Before You Pay That Medical Bill

**[Open the free U.S. bill-review kit](https://gerrygao1995-coder.github.io/the-american-life-playbook/medical-bills/)**

Choose a route for a bill/EOB mismatch, insurance denial, unaffordable balance, or uninsured/self-pay bill. The kit includes checklists, conversation scripts, clearly labeled fictional examples, official sources, and a printable blank contact log. No signup or bill upload is required.

This is an administrative guide, not a determination of eligibility, an appeal filing, or a promise of savings. AI-assisted drafting and source checking are disclosed. Independent professional review remains outstanding.

## Maintain this page

- Edit content.json for prose and claim-specific source records. Preserve route and source IDs.
- Edit template.html, kit.css, and kit.js for presentation and interaction.
- Run `node scripts/build-medical-kit.mjs` from the repository root to regenerate index.html.
- Check all four routes, source links, keyboard access, copying, printing, and a narrow screen before publishing.
- Use the [contribution instructions](../CONTRIBUTING.md) for corrections. Public issues must not include bills or private case records.

The page works as a static site. Keep its local CSS and JavaScript beside index.html when downloading it; official source links require internet access. Use your browser's print dialog to print or save as PDF.
